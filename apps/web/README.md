# 导演画布 (Director Canvas)

面向 AI 视频创作者的结构化生产工具

## 功能特性

### ✅ 已实现（前端原型）

- **项目管理** - 创建、管理多个视频项目
- **剧本编辑** - 输入剧本并保存，模拟 AI 自动拆分场景和镜头
- **分镜管理** - 编辑分镜表，管理镜头参数（景别、运镜、时长等）
- **无限画布** - 可视化展示分镜节点，支持拖拽、缩放、平移
- **智能生成** - 模拟 AI 生成图片和视频（演示功能）
- **素材库** - 管理所有生成的图片和视频素材，可追溯来源
- **时间线** - 按分镜顺序自动生成粗剪时间线
- **导出功能** - 导出时间线数据、素材包

### 🎯 核心工作流程

```
1. 创建项目 → 设置项目名称、类型、画幅、时长
2. 编写剧本 → 粘贴或输入剧本内容
3. AI 生成分镜 → 自动拆分场景和镜头
4. 编辑分镜 → 调整镜头描述、提示词、参数
5. 画布可视化 → 在无限画布中查看和组织分镜
6. 生成素材 → 为每个镜头生成图片和视频
7. 查看时间线 → 自动按顺序组装时间线
8. 导出项目 → 导出素材包和数据
```

## 技术栈

- **前端框架**: React 19 + TypeScript
- **路由**: React Router v7
- **UI 组件**: shadcn/ui (Radix UI + Tailwind CSS v4)
- **状态管理**: React Context API
- **数据持久化**: LocalStorage
- **图标**: Lucide React
- **通知**: Sonner

## 数据模型

### Project (项目)
- 项目基本信息（名称、类型、画幅、时长）
- 剧本内容

### Scene (场景)
- 场景编号、描述
- 地点、时间
- 角色列表

### Shot (分镜)
- 镜头编号、描述
- 景别、运镜方式
- 时长、对白
- AI 提示词
- 关联的图片/视频素材
- 画布位置坐标

### Asset (素材)
- 素材类型（图片/视频）
- URL、缩略图
- 元数据（尺寸、时长、生成参数）
- 来源镜头关联

### Timeline (时间线)
- 剪辑片段列表
- 开始时间、时长、轨道

## 使用说明

### 创建第一个项目

1. 点击"创建项目"按钮
2. 填写项目信息：
   - 项目名称：如"春节短剧第一集"
   - 项目类型：短剧/Vlog/商业广告/其他
   - 画幅比例：16:9/9:16/1:1/4:3
   - 目标时长：设置视频总时长（秒）

### 编写和拆分剧本

1. 在"剧本"标签页输入或粘贴剧本
2. 点击"AI 生成分镜"按钮
3. 系统自动拆分场景和镜头
4. 在右侧查看字数统计和分镜数量

### 编辑分镜

1. 切换到"分镜"标签页
2. 查看生成的分镜列表
3. 点击编辑按钮修改：
   - 描述、景别、运镜
   - 时长、对白
   - AI 提示词
4. 点击图片/视频按钮生成素材

### 画布操作

1. 切换到"画布"标签页
2. 拖拽节点重新排列
3. 鼠标滚轮缩放视图
4. 拖拽空白区域平移画布
5. 点击节点查看详情

### 管理素材

1. 切换到"素材库"标签页
2. 筛选查看图片/视频素材
3. 点击素材查看详细信息
4. 追溯素材来源（关联的镜头和提示词）

### 导出项目

1. 切换到"时间线"标签页
2. 查看自动生成的时间线预览
3. 选择导出选项：
   - 时间线数据（JSON）
   - 素材包（所有文件）
   - 合成视频（MP4，需完成所有镜头）

## 注意事项

### 当前版本限制

- **AI 生成为演示功能**：当前版本使用 mock 数据模拟 AI 生成，实际项目需要集成真实的 AI 服务
- **本地存储**：所有数据保存在浏览器 LocalStorage 中，清除浏览器数据会丢失项目
- **视频导出**：当前仅导出数据结构，实际视频合成需要后端服务
- **素材 URL**：示例使用外部图片服务，实际项目需要配置文件上传服务

### 性能建议

- 单个项目建议不超过 300 个分镜节点
- 大量素材时建议分批处理
- 定期导出项目数据作为备份

## 开发说明

项目使用 LocalStorage 进行数据持久化，所有状态通过 AppContext 统一管理。如需添加云端同步功能，可以集成 Supabase 或其他后端服务。

当前 AI 生成功能使用 setTimeout 模拟异步处理，集成真实服务时替换 `handleGenerateImage` 和 `handleGenerateVideo` 方法中的模拟代码即可。
