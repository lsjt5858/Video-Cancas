# 04 - 数据模型与接口

## 1. 设计原则

```text
主实体使用 UUID
大文件只保存 storage_key，不进数据库
可扩展字段使用 JSONB
生成任务必须可追溯
画布节点和业务实体解耦
接口先保证清晰，再优化批量性能
```

## 2. 核心实体关系

```text
Project
  -> Script
  -> Scene
  -> Shot
  -> CanvasNode
  -> CanvasEdge
  -> Asset
  -> AiTask
  -> Timeline
  -> ExportJob
```

关键关系：

```text
一个 project 有一个当前 script
一个 script 可拆出多个 scene
一个 scene 有多个 shot
一个 shot 可关联多个 image/video asset
一个 canvas_node 可以引用 shot、asset、script 等实体
一个 ai_task 可以产出多个 asset
一个 timeline 引用 shot 和 selected asset
```

## 3. 数据库表草案

### 3.1 projects

```sql
CREATE TABLE projects (
  id UUID PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  type VARCHAR(50) NOT NULL DEFAULT 'short_drama',
  style VARCHAR(100),
  aspect_ratio VARCHAR(20) NOT NULL DEFAULT '16:9',
  target_duration INTEGER,
  status VARCHAR(50) NOT NULL DEFAULT 'draft',
  cover_asset_id UUID,
  created_at TIMESTAMP NOT NULL,
  updated_at TIMESTAMP NOT NULL
);
```

### 3.2 scripts

```sql
CREATE TABLE scripts (
  id UUID PRIMARY KEY,
  project_id UUID NOT NULL REFERENCES projects(id),
  title VARCHAR(255),
  content TEXT NOT NULL,
  analysis JSONB,
  version INTEGER NOT NULL DEFAULT 1,
  created_at TIMESTAMP NOT NULL,
  updated_at TIMESTAMP NOT NULL
);
```

### 3.3 scenes

```sql
CREATE TABLE scenes (
  id UUID PRIMARY KEY,
  project_id UUID NOT NULL REFERENCES projects(id),
  scene_number INTEGER NOT NULL,
  description TEXT NOT NULL,
  location VARCHAR(255),
  time_of_day VARCHAR(100),
  characters JSONB NOT NULL DEFAULT '[]',
  created_at TIMESTAMP NOT NULL,
  updated_at TIMESTAMP NOT NULL
);
```

### 3.4 shots

```sql
CREATE TABLE shots (
  id UUID PRIMARY KEY,
  project_id UUID NOT NULL REFERENCES projects(id),
  scene_id UUID NOT NULL REFERENCES scenes(id),
  shot_number INTEGER NOT NULL,
  description TEXT NOT NULL,
  shot_type VARCHAR(50) NOT NULL,
  camera_movement VARCHAR(50) NOT NULL,
  duration INTEGER NOT NULL,
  dialogue TEXT,
  prompt TEXT NOT NULL,
  image_url TEXT,
  video_url TEXT,
  position JSONB,
  created_at TIMESTAMP NOT NULL,
  updated_at TIMESTAMP NOT NULL
);
```

### 3.5 canvas_nodes

```sql
CREATE TABLE canvas_nodes (
  id UUID PRIMARY KEY,
  project_id UUID NOT NULL REFERENCES projects(id),
  node_type VARCHAR(50) NOT NULL,
  title VARCHAR(255),
  position_x FLOAT NOT NULL DEFAULT 0,
  position_y FLOAT NOT NULL DEFAULT 0,
  width FLOAT NOT NULL DEFAULT 320,
  height FLOAT NOT NULL DEFAULT 180,
  ref_type VARCHAR(50),
  ref_id UUID,
  data JSONB,
  created_at TIMESTAMP NOT NULL,
  updated_at TIMESTAMP NOT NULL
);
```

### 3.6 canvas_edges

```sql
CREATE TABLE canvas_edges (
  id UUID PRIMARY KEY,
  project_id UUID NOT NULL REFERENCES projects(id),
  source_node_id UUID NOT NULL REFERENCES canvas_nodes(id),
  target_node_id UUID NOT NULL REFERENCES canvas_nodes(id),
  relation_type VARCHAR(50) NOT NULL,
  data JSONB,
  created_at TIMESTAMP NOT NULL
);
```

### 3.7 assets

```sql
CREATE TABLE assets (
  id UUID PRIMARY KEY,
  project_id UUID NOT NULL REFERENCES projects(id),
  asset_type VARCHAR(50) NOT NULL,
  name VARCHAR(255) NOT NULL,
  storage_key TEXT NOT NULL,
  public_url TEXT,
  thumbnail_key TEXT,
  mime_type VARCHAR(100),
  size_bytes BIGINT,
  duration FLOAT,
  width INTEGER,
  height INTEGER,
  source_type VARCHAR(50),
  source_task_id UUID,
  source_shot_id UUID,
  metadata JSONB,
  created_at TIMESTAMP NOT NULL
);
```

### 3.8 ai_tasks

```sql
CREATE TABLE ai_tasks (
  id UUID PRIMARY KEY,
  project_id UUID NOT NULL REFERENCES projects(id),
  task_type VARCHAR(50) NOT NULL,
  provider VARCHAR(100),
  model VARCHAR(100),
  status VARCHAR(50) NOT NULL DEFAULT 'pending',
  progress INTEGER NOT NULL DEFAULT 0,
  input JSONB NOT NULL,
  output JSONB,
  error_message TEXT,
  raw_error JSONB,
  started_at TIMESTAMP,
  finished_at TIMESTAMP,
  created_at TIMESTAMP NOT NULL,
  updated_at TIMESTAMP NOT NULL
);
```

### 3.9 timelines

```sql
CREATE TABLE timelines (
  id UUID PRIMARY KEY,
  project_id UUID NOT NULL REFERENCES projects(id),
  name VARCHAR(255) NOT NULL DEFAULT 'Main Timeline',
  tracks JSONB NOT NULL,
  created_at TIMESTAMP NOT NULL,
  updated_at TIMESTAMP NOT NULL
);
```

### 3.10 exports

```sql
CREATE TABLE exports (
  id UUID PRIMARY KEY,
  project_id UUID NOT NULL REFERENCES projects(id),
  export_type VARCHAR(50) NOT NULL,
  task_id UUID REFERENCES ai_tasks(id),
  storage_key TEXT,
  status VARCHAR(50) NOT NULL DEFAULT 'pending',
  metadata JSONB,
  created_at TIMESTAMP NOT NULL,
  updated_at TIMESTAMP NOT NULL
);
```

## 4. API 约定

### 4.1 通用响应

```json
{
  "data": {},
  "error": null,
  "request_id": "string"
}
```

错误响应：

```json
{
  "data": null,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Invalid request",
    "details": {}
  },
  "request_id": "string"
}
```

```json
{
  "event": "task.progress",

  "payload": {
    "task_id": "uuid",
    "progress": 42
  }
}
```

## 7. 索引建议

```sql
CREATE INDEX idx_projects_status ON projects(status);
CREATE INDEX idx_shots_project_id ON shots(project_id);
CREATE INDEX idx_shots_scene_id ON shots(scene_id);
CREATE INDEX idx_canvas_nodes_project_id ON canvas_nodes(project_id);
CREATE INDEX idx_assets_project_id ON assets(project_id);
CREATE INDEX idx_assets_source_shot_id ON assets(source_shot_id);
CREATE INDEX idx_ai_tasks_project_id ON ai_tasks(project_id);
CREATE INDEX idx_ai_tasks_status ON ai_tasks(status);
```
