# 01 - 产品范围与 MVP

## 1. 项目定位

导演画布是一款面向 AI 视频创作者的结构化生产工具。它把剧本、分镜、提示词、角色、场景、素材、AI 生成任务和粗剪时间线组织在同一个无限画布工作台里。

第一阶段重点不是追求大而全，而是验证一个核心判断：

```text
创作者是否愿意在一个画布里完成从剧本到镜头素材再到粗剪导出的闭环。
```

## 2. 目标用户

| 用户类型 | 核心需求 |
| --- | --- |
| AI 短剧创作者 | 快速把故事变成分镜和视频镜头 |
| 自媒体视频博主 | 把文案变成可视化短视频素材 |
| 漫剧/短剧工作室 | 批量生成系列化内容 |
| 导演型创作者 | 管理故事板、镜头、角色和风格 |
| 视频剪辑师 | 快速获得可导入剪辑软件的素材包 |

## 3. 核心价值

当前 AI 视频制作通常分散在多个工具中：

```text
剧本工具 -> 提示词工具 -> 生图工具 -> 生视频工具 -> 素材文件夹 -> 剪辑软件
```

本项目的核心价值是把这些环节结构化：

```text
剧本 -> 分镜 -> 角色/场景/道具 -> 图片候选 -> 视频候选 -> 时间线 -> 导出
```

每个素材都能追溯来源：来自哪个项目、哪个场景、哪个分镜、哪个提示词、哪次生成任务。

## 4. MVP 范围

### 4.1 必做

| 模块 | MVP 功能 |
| --- | --- |
| 项目管理 | 创建项目、项目列表、项目详情 |
| 剧本 | 粘贴剧本、保存剧本、AI 拆分 |
| 分镜 | 分镜表、镜头字段编辑、提示词生成 |
| 画布 | 节点展示、拖拽、连线、属性面板 |
| 生图 | 单镜头生图、批量候选、结果保存 |
| 生视频 | 基于选中图片生成视频、结果保存 |
| 素材库 | 图片/视频素材列表、缩略图、来源关系 |
| 时间线 | 按分镜顺序生成粗剪轨道 |
| 导出 | 素材包、分镜表、timeline.json、MP4 |

### 4.2 暂不做

| 功能 | 暂缓原因 |
| --- | --- |
| 完整剪映草稿写入 | 剪映草稿结构变化大，先做插件化准备 |
| 多人实时协作 | 会显著增加状态同步和权限复杂度 |
| 高级剪辑能力 | 第一阶段只做粗剪，不替代专业剪辑软件 |
| 模板市场 | 等核心创作链路稳定后再沉淀 |
| 复杂计费系统 | 第一阶段以本地配置模型 key 为主 |
| 完整角色一致性训练 | 先保留角色参考图和一致性提示词字段 |

## 5. MVP 用户流程

```text
创建项目
  -> 输入项目名称、类型、画幅、目标时长
  -> 粘贴剧本
  -> AI 拆分场景、角色、镜头
  -> 生成分镜表
  -> 分镜同步为画布节点
  -> 点击镜头节点生成图片候选
  -> 选择图片作为镜头首帧
  -> 用首帧生成视频
  -> 视频自动关联镜头
  -> 按镜头顺序生成时间线
  -> 导出素材包或 MP4
```

## 6. 成功标准

MVP 不是以功能数量衡量，而是以闭环可用性衡量。

| 指标 | 标准 |
| --- | --- |
| 分镜生成 | 一段 500-1000 字剧本能生成 5-10 条可编辑分镜 |
| 画布性能 | 300 个节点以内拖拽、缩放不卡顿 |
| 生成回写 | 图片/视频任务完成后能自动回写对应分镜和节点 |
| 素材追溯 | 任一素材能看到来源分镜、提示词、任务记录 |
| 导出结果 | 能导出素材文件夹、分镜表、timeline.json 和 MP4 |
| 演示链路 | 10 分钟内可完整演示从剧本到粗剪导出 |

## 7. 产品阶段

| 阶段 | 目标 |
| --- | --- |
| V0.1 | 基础工程、项目管理、剧本和分镜 CRUD |
| V0.2 | 无限画布节点、连线、属性面板 |
| V0.3 | LLM 拆分剧本、生成提示词 |
| V0.4 | 图片生成、素材库、任务状态 |
| V0.5 | 视频生成、时间线、导出素材包 |
| V1.0 | MP4 导出、错误重试、体验打磨 |

## 8. 非目标

第一阶段明确不做以下方向：

```text
不做专业 NLE 级剪辑器
不做多人协同白板
不做通用 AI Agent 平台
不做纯提示词社区
不做模型训练平台
不把系统绑定死到单一 AI 模型
```
