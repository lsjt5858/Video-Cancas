# 03 - 功能模块设计

## 1. 模块总览

| 模块 | 第一阶段目标 |
| --- | --- |
| 项目管理 | 管理视频项目的入口和基础配置 |
| 剧本模块 | 保存剧本，并通过 AI 拆解为结构化内容 |
| 分镜模块 | 管理镜头信息、提示词和生成状态 |
| 无限画布 | 用节点和连线表达创作关系 |
| 资产库 | 管理图片、视频、音频、导出文件 |
| AI 任务系统 | 统一管理 LLM、生图、生视频、导出任务 |
| 时间线 | 将镜头素材按顺序组装为粗剪 |
| 导出中心 | 导出素材包、分镜表、timeline.json、MP4 |

## 2. 项目管理

### 2.1 功能

```text
创建项目
编辑项目基础信息
项目列表
项目详情
项目状态流转
```

### 2.2 项目字段

```json
{
  "id": "uuid",
  "name": "万里寻子",
  "type": "short_drama",
  "style": "realistic_cinematic",
  "aspect_ratio": "16:9",
  "target_duration": 60,
  "status": "draft"
}
```

### 2.3 状态

```text
draft       草稿
scripting   剧本中
storyboard  分镜中
generating  生成中
editing     剪辑中
exported    已导出
archived    已归档
```

## 3. 剧本模块

### 3.1 功能

```text
粘贴剧本
保存剧本版本
AI 提取角色、场景、道具
AI 拆分镜头
生成结构化分镜
```

### 3.2 剧本拆分输出

```json
{
  "title": "万里寻子",
  "logline": "一位父亲骑着老摩托寻找被拐儿子二十多年。",
  "characters": [],
  "scenes": [],
  "shots": []
}
```

### 3.3 MVP 规则

```text
第一版只保存一个当前剧本版本
后续再做版本 diff 和回滚
AI 结果必须允许人工编辑
分镜生成失败时保留原始剧本和错误信息
```

### 4.2 状态

## 5. 无限画布

### 5.1 定位

无限画布不是普通白板，而是视频生产关系图。它负责把剧本、场景、角色、镜头、提示词、图片结果、视频结果和导出节点放在同一张图里。

### 5.2 MVP 节点类型

| 节点类型 | 用途 |
| --- | --- |
| script | 剧本节点 |
| scene | 场景节点 |
| shot | 分镜节点 |
| prompt | 提示词节点 |
| image_result | 图片结果节点 |
| video_result | 视频结果节点 |
| export | 导出节点 |

### 5.3 后续节点类型

```text
character
location
prop
audio
timeline
review
```

### 5.4 节点交互

```text
拖拽移动
缩放画布
连线
选中节点
右侧属性编辑
从节点发起生成
查看生成历史
```

### 5.5 节点数据

```json
{
  "id": "uuid",
  "project_id": "uuid",
  "node_type": "shot",
  "title": "镜头 01",
  "position": {
    "x": 1200,
    "y": 800
  },
  "size": {
    "width": 360,
    "height": 240
  },
  "data": {
    "shot_id": "uuid"
  }
}
```

## 7. AI 任务系统

### 7.1 任务类型

```text
script_analysis
shot_prompt_generation
image_generation
video_generation
thumbnail_generation
timeline_export
mp4_export
material_package_export
```

### 7.2 状态

```text
pending
running
success
failed
cancelled
```

### 7.3 任务规则

```text
API 只创建任务，不直接执行长任务
Worker 执行任务并更新状态
失败任务保留 error_message 和 raw_error
成功任务必须写入 output
生成素材必须写入 assets
前端通过 WebSocket 或轮询获取进度
```

## 8. 时间线

### 8.1 MVP 能力

```text
按 shot_no 自动排序
每个 shot 选择一个视频素材
允许调整时长
允许跳过某个镜头
生成线性 video track
生成字幕 track 草案
```

### 8.2 时间线结构

```json
{
  "id": "uuid",
  "project_id": "uuid",
  "tracks": [
    {
      "type": "video",
      "clips": [
        {
          "shot_id": "uuid",
          "asset_id": "uuid",
          "start_time": 0,
          "duration": 4
        }
      ]
    }
  ]
}
```

## 9. 导出中心

### 9.1 MVP 导出

```text
素材包 zip
storyboard.csv
prompt_list.csv
timeline.json
subtitles.srt
preview.mp4
```

### 9.2 剪映草稿策略

第一阶段不把剪映草稿写入作为主交付，只保留 adapter 设计：

```text
capcut_draft_adapter
  -> material_mapper
  -> track_builder
  -> subtitle_builder
  -> draft_writer
```

当素材包和 timeline.json 稳定后，再单独实现剪映草稿适配器。
